# Entregas e validação com o professor

Não envie a chave privada do Firebase nem dados reais de clientes ao professor. Para a demonstração pública, use um ambiente com dados de teste e acesso adequado.

## Confirmação sobre o banco de dados

Texto sugerido para a equipe enviar ao professor:

> Professor(a), o enunciado cita PostgreSQL, MySQL e MongoDB. Nosso projeto usa Cloud Firestore, um banco NoSQL, porque reaproveita os dados existentes do estabelecimento. O Firestore atende ao requisito da disciplina ou devemos migrar para uma das opções listadas?

**Resposta:** pendente. A equipe deve registrar a resposta real e, se o professor exigir, planejar a migração antes da entrega.

## Roteiro sugerido para vídeo de até cinco minutos

1. Apresentar a equipe, o estabelecimento e o objetivo do cardápio digital.
2. Navegar pelas categorias, abrir detalhes, adicionar itens e enviar um pedido com dados de teste.
3. Entrar no painel, mostrar o pedido recebido, atualizar seu status e mostrar o acompanhamento do cliente.
4. Cadastrar ou editar um produto de teste com imagem e mostrar a documentação em `/api/docs`.
5. Mostrar o repositório e explicar a API Node.js, Firebase Authentication, Firestore e a transmissão em tempo real.

O roteiro é uma orientação; a gravação, as confirmações e o preenchimento do relatório precisam ser feitos pela equipe.
